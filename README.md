One funny text message from your future self, under 200 characters — no setup, no context, just the message as it would arrive. The entry was picked from a five-candidate tournament judged on the kit's criteria: whether the joke lands, whether the voice feels like a real future self, how well every character is used, and how fresh the angle is.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
